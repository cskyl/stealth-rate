# Instruction revision scope

Status: synthetic demonstration and instrument review only; no new human results or approved recruitment.

The current demonstration asks what the main sound/motion is and whether a clip seems edited. This revision clarifies those existing questions without silently claiming that the combined task is an unbiased measurement of spontaneous noticeability or human resistance to an attack.

Participant materials must explain playback, all rating anchors, uncertainty, practice, interruption/recovery and manual file return in everyday EN/ZH language. Use invented worked examples, clearly labeled as examples rather than answers to the study clips. Do not expose target phrases, attack conditions, private mappings or previous raters' answers. The existing numeric ranges and output schema remain unchanged; raters should explicitly select ratings rather than unknowingly submit defaults.

One eventual scientific question: at matched model-tested operating points, how often do people notice an added cue? For a formal study, use paired sources across conditions but at most one variant of each source per person. Keep unprompted task-answering and explicit cue-detection in separate participant cohorts; optional audibility/word-identification is a separate targeted-listening task, not a synonym for naturalness. Freeze the instrument and predictions before new responses. Existing reference-workbook responses are prior work, not new confirmatory data.

The owner/advisor guide will specify a proposed pilot, task-specific anchors, paired-source assignment, private answer-key isolation, return workflow and unresolved approval/material decisions. No fixed sample-size adequacy or time estimate is claimed before a real-media pilot. This turn ships instructions and software; the owner must approve and freeze the actual study materials and consent before recruitment.
